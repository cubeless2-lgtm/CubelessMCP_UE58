# 퀴니 IK 편집과 수동 마커

1. 원본 영상과 현재 모캡 결과를 불러오고 대상 메시를 SKM_Quinn으로 지정합니다.
2. **현재 자세로 IK 편집**을 누릅니다. 모든 목표는 현재 애니메이션 자세에서 시작하므로 기본 IK 자세로 전환하지 않습니다.
3. 영상에서 원하는 위치로 탐색한 뒤 **현재 위치 마킹**을 누릅니다. 주황색 M 마커만 표시하며 자동 마커는 만들지 않습니다. 마커 클릭으로 탐색하고 수동 마킹 삭제로 제거합니다.
4. 시작 마커로 이동해 **현재/마커→시작**, 끝 마커로 이동해 **현재/마커→끝**을 누릅니다. 숫자로 범위를 직접 지정할 수도 있습니다. 연결 시간은 지정한 범위 안에서 보정 강도가 부드럽게 증가/감소하는 시간입니다. 구간 밖은 유지합니다.
5. 구간 안으로 이동해 발·무릎·골반·손·팔꿈치 핸들을 선택하고 W로 이동하거나 E로 회전합니다. 무릎/팔꿈치는 굽힘 방향을 정합니다. 손 확대 메뉴에서 손끝을 선택하면 손가락 세 관절을 함께 조정합니다. 골반을 이동하면 발 목표를 유지하며 다리를 풉니다. 뼈 길이는 늘리지 않습니다.
6. Ctrl+Z, Ctrl+Y 또는 버튼으로 보정 한 단계를 취소/복원합니다. 여러 컨트롤과 여러 구간을 별도 레이어로 편집할 수 있습니다. 같은 컨트롤과 같은 범위의 재편집은 그 레이어를 갱신합니다.
7. **새 애니메이션 저장**으로 새 표준 AnimSequence를 저장합니다. 기존 영상/애니메이션은 유지됩니다. 저장된 결과를 기준으로 핸들을 다시 준비하며 이전 보정을 중복 적용하지 않습니다.

GIF/보조 영상에 의한 보정과 0.5초 간격의 자동 대표 프레임 추론은 제거했습니다. 전체 모캡의 기존 모델·프레임 수·계산 품질 설정은 변경하지 않습니다. 본 편집 호환 API는 수동으로 지정한 마커에서 사용할 수 있습니다. IK 편집은 마커 프레임만으로 제한하지 않으며 지정 구간 안에서 사용할 수 있습니다.

직접 제어는 [WINDOW_API.md](WINDOW_API.md)를 참고하세요. 모든 보정 코드는 에디터 전용이며 결과 애니메이션은 별도 IK 플러그인 없이 재생할 수 있습니다.
