# 보조 정면 참고와 자세 변환 검증

UE5.8.4 CL58902052의 같은 프로젝트 Development Editor에서 검증했습니다. 마지막 빌드는 build-provenance.log에서 성공했습니다. 직접 MCP/Python API만 사용했습니다.

- Q 선택, W 이동, E 회전, R 스케일 버튼과 기즈모/수치 입력을 연결했습니다. 숫자 편집 포커스에서는 Q/W/E/R을 처리하지 않습니다. 직접 제어는 같은 기즈모 변환 경로입니다.
- 월드 Z 이동5cm, 월드 회전5도, 로컬 균일 스케일1.1배와 Undo/Redo가 프리뷰에 반영됐습니다. 새 AnimSequence 저장 후 새 Editor에서 재로딩했고160개 다른 본의 raw 트랙은 유지했습니다. 편집한 본의 raw 이동/스케일도 기대값과 일치했습니다. 기존 압축 설정에서 재생 위치 차이는 약2.14mm, 회전 차이는0.0039도였습니다.
- 자동 키 기본값은0.5초입니다. 300프레임에서21키의 실제 대표 분석을 완료했고 준비 시간은70.728초였습니다. 이는 전체 고품질 최종 추론 시간이 아닙니다. 전체 계산/손 파이프라인은 실행하지 않았고 기존 설정은 유지했습니다. 수동 마커/보정 곡선/간격 Undo와 같은 입력 재분석 병합을 실행했습니다.
- imagegen 내장 도구로 만든5장과 대응 원본을1024×576 캔버스에 비율 보존/여백 방식으로 정규화했습니다. GIF5장10초, MP4 300프레임30fps이며 모든프레임을 가장 가까운 키 이미지와 대조했습니다. 전환은38/113/188/262입니다. 생성뷰는 실제 깊이 관측/보정된 카메라가 아니며 자동 추론 융합은 없습니다.
- 보정안 prepare는 검증된 JSON만 저장하며 본/보정 곡선을 바꾸지 않습니다. commit에서 명시적으로 반영하고 원본/곡선이 달라진 보정안은 거부합니다. 새 후보 저장과 provenance, 준비 중 저장 거부를 확인했습니다. 검사용 각도는 최종 자세에 남기지 않았습니다. 실제 모션 품질/깊이 정확도 향상은 검증하지 않았습니다.
- 본만/본+모델/모델만 표시, 보조5키 원본/퀴니 동기화, 숨김 복원, 정지 후 재생 반복을 확인했습니다. 원본3개 SHA256은 과거 보호 지문과 일치합니다.

Editor PID 32152를 사용자에게 인계했습니다. HandFront_v4/Quinn과 원본 및1K 보조 패널을5초에 표시하고 회전 모드로 열어 두었습니다. 보정값/Undo/준비안/이전 검증용 provenance는 비워져 있습니다. 이 프로세스는 사용자 인계이며 정리 대상으로 닫지 않습니다.

물리 키보드/마우스 입력, 독립 스레딩/수명 리뷰와 새 게임 패키징은 not_run입니다. Git commit/push와 배포 ZIP 재생성은 하지 않았습니다. 기록의 최초 빌드 타입 오류와 검증 스크립트의 Python 반환값 오해는 보존했으며 수정 후 성공 결과를 별도로 기록했습니다.
