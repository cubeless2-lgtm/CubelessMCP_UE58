# HandFlow 오른손 검출 복구와 Manny 손 접촉 개선

2026-11-08, UE 5.8.4 CL58902052. test2의 같은 전신 에셋과 Manny/RTG_CBM_SMPL_to_Manny, 30fps·244프레임, Hand Strength 1, HandFlow FP32/seed0/ODE3/overlap8 조건에서 비교했다. 전신 추출, 모델 재학습, 관절 각도 제한, WiLoR/MediaPipe 회전 혼합, 컴퓨터 유즈는 수행하지 않았다.

## 원인과 수정

5.5초(frame165) 오른손 YOLO 후보는 약0.221로 기존0.30 기준에 미달했다. 확대 검출은 팔/옷을 손으로 잡는 오검출도 발생했다. `Tools/handflow_detection.py`는 기존 검출을 유지하고, 빠진 손에 한해0.15 이상 약한 후보를 확인한다. 같은 좌우 클래스, 신뢰도0.5 이상 자기 손목, 반대 손목보다 가까운 거리, 반대 손 박스와의 중복 배제, 앞뒤0.35초 안의 원래 강한 검출 두 개, 박스 크기·손목 상대 위치가 모두 뒷받침할 때만 복구한다. 복구한 검출을 또 다른 복구의 근거로 사용하지 않는다.

약한 복구 특징을 HandFlow 시간축 네트워크에 직접 넣은 중간 실험에서는 주변 창의 출력도 변했다. 최종 코드는 원래 강한 관측만 시간축 특징으로 사용하고, 약한 관측은 기존 HaMeR 영상 재투영 보정의 낮은 신뢰도 관측으로 사용한다. 다른 모델의 회전을 섞지 않는다. 최종 시간축 출력과 직전 출력의 최대 차이는7.59e-6rad로, 추가 HaMeR 배치에 따른 작은 수치 차이가 남는다.

검출을 복구하는 것만으로 관통은 해소되지 않았다. 양손은 독립적으로 추정되고, 기존 리타깃은 영상 인물과 체형이 다른 Manny 손가락의 부피를 고려하지 않았다. 검출 복구만 한 중간 결과의 frame165 교차 모서리는204→215로 오히려 증가했다.

`Tools/handflow_contact.py`는 실제 타깃 메시에서 얻은 손가락 길이·두께와 기존 리타깃 보정을 이용해 **타깃 공간의 접촉 비용**을 계산한다. 공통 UE 손가락 쿼터니언의 잔차만 최적화하며 손목·전신·메타카팔은 이 단계의 변수가 아니다. 손가락과 반대 손가락/손바닥의 겹침 비용, 원래 자세에 대한 비용0.5, 시간축 잔차 비용12를120회 Adam(lr0.015)으로 함께 줄인다. 각도/속도 상한은 없다. 접촉 전후0.1초의 짧은 구간을 함께 계산해 보정의 진입·이탈을 연결한다.

타깃 두께는 LOD0 표면의 지배적인 스킨 본을 기준으로 측정한 단면 반경65백분위수이며, 드문 표면 표본 사이의 패드를 고려해 손가락 반경1.1배와 손바닥 반경1.4배의 근사를 사용한다. 손가락만 피하게 하면 반대 손바닥으로 밀려 들어가는 경우가 있어 손바닥 부피도 포함했다. 정확한 메시 충돌 해석이나 숨은 손가락 정답을 보장하는 방식은 아니다.

`CBMHands.inl`의 읽기 전용 준비 분기가 실제 리타깃 보정과 타깃 기하·원본 손목 궤적을 외부 작업에 전달한다. 세 가지 비항등 회전 탐침으로 활성 리타깃과 분석적 FK가 일치하는지 검사하며, 중복 보정을 출력에 적용하지 않는다. 타깃 준비 불가, 지원하지 않는 계층/스케일, 부분 Hand Strength, 한쪽 손 전체 미관측에서는 접촉 보정을 생략하고 이유를 기록한다. 기존 추론/베이크는 유지된다. 접촉 최적화는 기존 외부 Python 비동기 작업에서 실행되며, 취소는 기존 프로세스 트리 취소를 사용한다. 미분 그래프는256프레임 단위로 나눈다.

- 타깃 분석 FK와 실제 Manny를244프레임×38본 비교: 최대 회전 차이0.0000812°, 위치 차이0.0000308cm. 네이티브 회전 탐침 오차2.98e-8rad. 청크별 FK 차이는 허용한 FP32 수치 오차 이내다.
- 최종 네이티브 저장 검사: 비손가락123트랙×244샘플 차이0. 별도 AnimPose 평가에서도 원본/수정 전/최종의 손목이 정확히 같다.

- 완전한 비동기 경로 시험은 첫 접촉 근사에서87.9초(직전83.8초), worker65.15초, worker 프로세스 트리 RSS6754MiB(직전6752MiB), CUDA 할당 피크2788MiB였다. 에디터 별도 프로파일 피크13496MiB. Slate callback260회, 최대 wall gap1.950초로 순간 지연이 없다는 뜻은 아니다.
- 마지막 손바닥/여유 반경 변경은 같은 저장된 **접촉 보정 전** 손 회전으로 접촉 단계만3.96초 재실행하고, 같은 에디터에서 베이크·저장·28장 동기화 캡처·전체 회전 비교를 수행했다. 마지막 설정의 전체 경로 시간을 새로 측정한 것으로 표현하지 않는다. 전신 추론은 전 과정에서 반복하지 않았다.
- 손 캐시 키에는 영상, 모델/런타임, Python 코드, 타깃 기하·보정·손목 궤적을 포함한 설정이 들어간다. `contact_evidence.npz`도 캐시 산출물에 포함했다. `model_evidence.npz`는 접촉 이전 모델/영상 보정 결과이고, `contact_evidence.npz`는 접촉 전후 UE 회전이며, 실제 Manny는 네이티브 평가/캡처로 별도 확인했다.
