# MediaPipe 손 관측 기하 검증과 test2 회귀 비교

2026-11-08. test3의14.03초·17.3초 손가락 붕괴를 조사해 **공통 MediaPipe 처리 코드**를 수정했다. 두 구간에서 원시 관측의 문제를 회전 변환 전에 거절/재검출하고, 실제 Manny의 뒤집힘·과도한 말림이 개선된 것을 확인했다. 특정 영상명·프레임 번호를 처리 코드에 넣지 않았다. 모델 가중치 재학습이나 관절 각도 제한은 하지 않았다.

## 원인

1. **잘못된3D 관측이 정상 관측으로 통과했다.** 기존 코드는 좌우 분류 신뢰도와 손목 위치를 검사했지만, 손바닥 기준축과 마디 길이를 검사하지 않았다. 좌우 분류 점수는 손 자세 정확도 점수가 아니다.
2. test3 f420~423에서 손바닥 법선이 갑자기 반전하고 손바닥 폭·일부 마디 길이가 붕괴했다. f421의 새끼손가락/약지 첫 마디는 약3mm까지 작아졌다. 원본에서는 손을 허리에 올린 자세가 이어진다. 이 불안정한3D 정보를 palm-relative 회전으로 변환하면서 손가락 회전이 크게 바뀌었다. 문제가 처음 나타난 단계는 Manny 리타깃 이전이다.
3. f517~520도 손바닥 기준축과 짧은 마디의 깊이 추정이 불안정했다. f519의 기존 반사 크롭 관측보다90도 회전 입력의 관측이 더 일관된 기하를 제공했다.
4. 기하 오류를 먼저 거절한 뒤에도 f420의 단독 손바닥 반전이 남았다. 다음 유효 관측까지 중간 누락이 있어 기존 필터의 인접3프레임 조건에 걸리지 않았다. 이 관측이 보간 기준으로 사용되면서 주변 프레임에도 영향을 줬다.

## 공통 수정

파일은 `Plugins/CubelessBodyMocap/Tools/` 아래에 있다.

- `hand_geometry.py`: 유한값, 손바닥 기준축의 수치적 안정성, 상대 마디 길이 붕괴, 최근 유효 관측 대비 크기 정규화한 마디 길이 일관성을 검사한다. 최근1초의 관측을 사용하며5개 미만이면 시간축 길이 검사를 적용하지 않는다. 한 마디의 중간 정도 오차만으로 전체 손을 거절하지 않고, 여러 마디의 불일치 또는 한 마디의 심한 붕괴를 요구한다.
- `hand_observations.py`: 기하 검사에 실패한 후보는 조기 성공으로 취급하지 않고 다른 크롭·반사·회전 입력을 시도한다. ±90도 입력을 추가했다. 실제 기하 오류 후보를 관측한 경우에만2.0배·2.8배의 추가 문맥 크롭을 시도한다. 완전히 보이지 않는 손에 대한 검색을 무조건 확장하지 않는다.
- `hand_geometry.py`의 `reject_palm_flips`: 앞뒤3D 법선이 서로 일치하고 중간 법선만 반대이며,2D 손바닥 점이 앞뒤 관측의 보간 경로와 일치하는 경우에만 중간 관측을 거절한다. 지속적인 회전, 영상에서 확인되는 큰 이동, 긴 누락은 이 규칙으로 수정하지 않는다. 기존 짧은 누락 보간 정책이 거절된 관측을 처리한다.
- `refine_mediapipe.py`: 위 검사를 추론·회전 변환 흐름에 연결하고, 거절 사유와 원시 관측/최종 유효 마스크를 진단 파일로 남긴다. 회전 솔버와 기존 보간·감쇠·원본 복귀 정책 자체는 유지했다.
- `test_hand_geometry.py`: 강체 변환·크기·좌우 반사 불변성, 굽힘 각도에 대한 비제한성, 붕괴 검출, 이력 만료, 짧은 누락 사이 깊이 반전과 실제 움직임의 구분을 검증한다.

마디 길이·기준축 검사는 측정값의 신뢰도 검사다. 관절별 허용 각도를 정하거나 잘못된 회전을 특정 각도로 잘라내지 않는다. 테스트에는 해부학적으로 불가능한 굽힘도 포함해, 길이가 유지되는 굽힘을 이 검사만으로 거절하지 않음을 확인했다.

## 중간안의 회귀와 최종 보완

초기 기하 검사안은 test2의 일부 유효 후보까지 과하게 거절했다. 원본 복귀가 왼손0→3, 오른손46→58프레임으로 늘었고, 약1초 왼손에서 기존 원본 손 모양으로 돌아가며 시각적으로 악화됐다. 이 결과를 그대로 최종본으로 사용하지 않았다.

여러 마디의 불일치를 요구하도록 길이 검사를 보완하고, 기하 오류가 발생한 경우에 한해 넓은 문맥을 재시도했다. test2 f28은2.8배/180도 입력에서 유효 관측을 회복했다. f20 오른손은 단일 마디의 중간 수준 변동 때문에 전체 손이 거절되던 문제를 해소했다. 최종 test2에서는 **새로 추가된 원본 복귀 프레임이0개**이고, 전체 원본 복귀 수도 기존0/46과 동일하다.

초기·중간 증거는 `Saved/CubelessBodyMocap/HandGeometry20261108/test2`, `test3`, `test2_final`, `test3_final`에 보존했다. **최종 실행 데이터는 `test2_release`, `test3_release`**이며, 최종 에셋은 아래 GeometryVerified 폴더의 결과다.

## 남은 한계

모든 구간이 개선된 것은 아니다. **test3 13.83초 오른손(f415)의 최대 순간 회전 변화는 약75°→118.99°로 커졌다.** 같은 구간의 손 형태는 전후 모두 관측이 어려우며, 주변의 깊이·손바닥 방향 불안정이 남아 있다. 따라서 전체 영상의 무회귀 또는 모든 손가락 튐 해결 판정은 하지 않는다. 요청된 두 왼손 구간의 개선과 test2의 위 회귀 범위를 구분한다.

관절 제한·충돌 방지·가려진 손의 정확한3D 복원은 추가하지 않았다. WiLoR worker 코드는 변경하지 않았고 전체 WiLoR 추론은 재실행하지 않았다. 향후 WiLoR가 자동 생성하는 MediaPipe 크롭 참조 관측은 이번 개선의 영향을 받을 수 있다. 독립 리뷰·전체 프레임의 수작업 정답 평가·패키징은 수행하지 않았다. Git stage/commit/push 없음.
