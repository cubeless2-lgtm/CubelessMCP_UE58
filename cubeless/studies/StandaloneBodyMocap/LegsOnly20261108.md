# FootMR 제거와 골반·다리 단독 보완 — 2026-11-08

FootMR 없이 기존 전신·HandFlow 결과에 골반·다리 보완만 적용하는 경로를 구현했다. 이후 사용자 요청에 따라 FootMR 선택 항목, 추론·준비·접지 회전 코드와 전용 모델/환경을 제거했다. 별도 백업은 만들지 않았다. 과거 결과 애셋과 검증 기록은 재작성하지 않았다.

## 사용 방법

1. `Lower Body`에서 원본 전신 또는 HandFlow 애니메이션을 `Foot Input Animation`으로 선택한다. 이미 하체를 보완한 결과를 재입력하면 중복 적용을 거절한다.
2. 원본 `Video`와 시간 구간을 지정하고 `Refine Pelvis and Legs from Video (Experimental)`을 켠다. 기본값은 꺼짐이다.
3. `Refine pelvis / legs`를 누른다. 전신·손 신경망 추론 없이 저장된 영상 관측과 대상 스켈레톤만 사용한다.
4. 비교 창의 `Before legs`는 원본 전신+HandFlow, `Pelvis / legs`는 하체 단독 보완본이다. 같은 영상 타임라인으로 전환한다.
5. `Apply cached legs`는 결과 JSON과 원본 데이터 GUID·형상 문맥이 일치할 때만 재적용한다.

`Lower Body Python`은 기존 준비된 손 환경의 numpy/scipy/psutil을 사용한다. FootMR, torch 모델 로드, 발 전용 가중치가 필요하지 않다. 기존 실행 환경에 패키지를 추가하거나 수정하지 않았다. 기본 Python 경로는 `ThirdParty/WiLoR/venv/Scripts/python.exe`지만 WiLoR 모델을 실행하는 것은 아니다.

## 회전 보존의 의미

**발목의 월드/애니메이션 컴포넌트 공간 방향**을 원본대로 보존한다. 종아리를 회전시키므로 발목 로컬 회전에는 반대 방향 보상이 들어간다. 발목 로컬 회전까지 비트 단위로 유지한다는 의미가 아니다. 발가락 로컬 트랙은 정확히 유지한다.

골반과 허벅지·종아리를 변경하고 `spine_01`을 역보상해 상체 월드 자세와 HandFlow 손·손목을 보존한다. 발목에는 종아리 역보상만 적용한다. FootMR 델타, 발목 접지 회전 최적화, 강제 발 평탄화, 관절 각도 제한, 모델 혼합은 없다. 발목 위치와 하체 스키닝은 변경될 수 있다.

native 적용 전에 상체 월드 위치/방향과 양 발목 월드 방향을 검증한다. 허용된8개 본 외153개 트랙은 저장 전 정확히 비교한다. 본 길이·스케일도 보존한다. 기존 애셋은 수정하지 않고 `_VideoLegs_` 이름의 `/Legs/` 애셋을 만든다.

## 제거 범위와 실패 기록

FootMR enum/설정/비교 버튼과 추론 경로를 제거했다. `run_foot_worker.py`, `prepare_footmr.py`, `foot_contact.py`를 삭제했다. `ThirdParty/FootMR` 모델·전용환경 폴더는 자동 삭제 승인이 두 차례 차단돼 사용자에게 경로를 안내했고, 사용자가 삭제한 뒤 경로 부재를 확인했다. 별도 백업은 만들지 않았다.

`FootMRInput.json`, `FootMR_Keypoints25.f32`, `FootMR_Camera.f32`, `FootMR_Boxes.f32`라는 기존 숫자 캐시 파일명은 저장된 전신 결과와의 호환을 위해 남아 있다. 실제 내용은 전신 추출의 영상 관측/카메라/박스이며 FootMR 모델 실행이나 의존성이 아니다. 역사적 검증 자료와 이전 생성 애니메이션은 남아 있다.

검증 초기 상태 스크립트가 공개되지 않은 `is_busy` Python API를 호출해 실패했고, 실제 공개 작업 상태 조회로 교정했다. 에디터 종료 요청 직전에 기존 프로세스가 이미 종료돼 요청은 수행되지 않았으며 종료 로그를 확인한 후 새 빌드를 실행했다. 검증 러너가 다음 영상 준비 중 Slate 재진입으로 첫 결과 완료를 중복 기록했으나 실제 두 작업은 각각1회 생성됐고, 파일·native 상태를 대조해 test3 기록만 복구했다. test2 영상 전환 직후 seek timeout은 준비된 플레이어 상태를 확인한 뒤 캡처를 완료했다. 실패 로그는 보존했다.

독립 코드 리뷰·다른 영상/체형/지형·패키지 실행은 미검증이다. 기존 MetaHuman 비의존 구조와 MCP 비의존 표준 AnimSequence 출력은 유지했다. Git staging/commit/push는 하지 않았다.
