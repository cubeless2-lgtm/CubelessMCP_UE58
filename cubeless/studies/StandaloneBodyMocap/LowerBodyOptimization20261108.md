# 하체 보완 속도·접지 개선 — 2026-11-08

test2/test3의 기존 전신·HandFlow·원시 FootMR 결과를 재사용하고, 하체 보완 계산과 Manny 결과만 다시 생성했다. 관절 각도 제한, 프레임 생략, 모델 혼합은 추가하지 않았다. 기존 결과는 보존하고 새 결과는 `/Game/_MCP_Temp/LowerFast/CubelessTests/20261108_R2/`에 저장했다.

## 병목과 변경

기존 test3 하체 계산을 별도로 프로파일링한 결과 94.04초 중 86.03초가 SciPy LSMR 선형 해법이었다. 36회 호출에서 총 46,374회 선형 반복이 발생했다. 이전 에디터 전체 작업 166.52초와 이 단독 측정 94.04초는 측정 범위·실행 시점이 다르므로 동일 수치로 취급하지 않는다.

`temporal_solver.py`는 잔차가 인접 3프레임에만 의존하는 구조를 이용한다. 모든 프레임과 목적함수를 유지하고 수치 미분을 묶어서 계산한 뒤, 대역 행렬 Cholesky로 감쇠 최소제곱 문제를 푼다. 품질을 낮추거나 추론 프레임을 줄여 얻은 가속이 아니다. 같은 기존 목적함수 시험에서 하체 계산은 2.57초였고 비용은 96,676→92,035로 낮아졌다. 이 시험은 최종 품질 보완 전의 성능 분리 시험이다.

최종 `target_video_lower_body_v3_banded`에는 다음을 함께 적용했다.

- 기존 발목 높이를 무조건 따라가던 항에 실제 신발 표면의 침투량을 반영한 부드러운 높이 목표를 넣었다. 기존 침투 자세를 목표로 고정하는 문제를 줄인다.
- 단안 약원근 투영에서 관측하기 어려운 깊이 방향의 골반 이동을 기존 결과에 더 강하게 연결했다. 새 해법이 더 수렴하면서 깊이 방향으로 불필요하게 움직이는 문제를 막는다.
- 보정량뿐 아니라 실제 골반·다리 전역 회전의 시간적 곡률도 평가한다. 원래 결과에 들어 있던 급변을 그대로 통과시키는 문제를 줄인다.
- 하체 모드의 발목 접지 해법도 대역 행렬로 바꾸고 침투·미끄러짐의 상대 가중치를 조정했다. 각도 범위나 하드 클램프는 없다.

발목 전용 모드는 이전 `sole_geometry_v5` 목적함수와 SciPy 해법을 그대로 사용한다. 공유 고속 후보가 test3 왼발 최대 침투를 악화시켜 적용 범위를 하체 모드로 한정했다. 실제 FootMR 환경에서 기존 test3 발목 전용 결과와 회전 배열이 정확히 같았다. 일반 시스템 Python에서 먼저 실행한 비트 단위 비교는 실패했으므로 환경을 일치시켜 재검증했다.
