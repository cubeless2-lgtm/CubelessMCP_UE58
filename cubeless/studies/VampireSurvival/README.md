# Crimson Dawn — 게임 기획과 변경 이력

현재 플레이 버전은 **V8: 모바일 세로720×1280, 10분 생존**이다. [V8 화면·키보드·터치 조작과 검수](UPDATE_V8.md)에서 세로 배경·UI,터치 패드/버튼과2.5초 달리기를 적용했다. 키보드 조작은 유지한다. [V7 회복 보상 감소](UPDATE_V7.md)의대체 회복20·녹색 구슬5%, [V6 조정](UPDATE_V6.md)의600초·보스9분·샤미 특수 반경0.9m·공격력 강화×1.2도 유지한다. [V5 전투·버튼·드롭](UPDATE_V5.md), [V4 검수](REVIEW_V4.md), [V3 한글 UI·대기 모션](UPDATE_V3.md), [V2 달리기·점프](UPDATE_V2.md)는 이전 이력이다. 아래 문서는 V1의 기획·검증 이력이며 최신 수치는 V8/V7/V6 문서를 따른다.

## 현재 버전 실행

UE 5.8.3 프로젝트에서 `/Game/VampireSurvival/Maps/L_CrimsonDawn`을 열고 새 에디터 창으로 PIE를 실행한다. 미리보기 창은432×768 또는720×1280으로 설정한다. 맵에 지정된 게임 모드가 타이틀부터 실행하므로 프로젝트의 기본 맵을 바꿀 필요는 없다. 조작과 최신 수치는 [V8 기록](UPDATE_V8.md)을 따른다.

게시 콘텐츠에는 게임 에셋43개,이미지·음원·폰트 원본과 OFL 라이선스가 들어 있다. 검증용 실행 파일,작업용 프로젝트,로컬 도구와 원시 로그는 저장소의 제외 규칙에 따라 게시하지 않는다. V8의 PIE 입력·레이아웃·Win64 패키징과 세로 실행은 확인했으며 휴대폰 실기기·APK/IPA와 전체600초 재검증은 미수행이다.

## 최초 기획 이력

작성일: 2026-10-27. 대상: UE 5.8.3, `/Game/VampireSurvival`. 최초 V1에서는 두 클래스 180초 입력 플레이 및 독립 Win64 패키징을 확인했다. 자세한 당시 증거와 제한은 [구현 기록](IMPLEMENTATION.md)에 정리했다. 독립 QA는 수행하지 않았다.

## 목표와 분위기

붉은 달이 떠 있는 폐허의 묘지에서 새벽까지 180초를 버티는 싱글플레이 도트풍 자동 전투 게임이다. 타이틀 → 궁수/검사 선택 → 생존 전투 → 승리/사망 결과 → 재도전으로 한 판이 완결된다. 전투 시간만 180초이며 성장 선택과 일시정지는 전투 시계를 멈춘다. 기존 게임의 캐릭터, 명칭, 그림은 복제하지 않는다.

위 항목은 참고작에 관한 사실과 본 프로젝트 설계 판단을 구분한 것이다. 아래 수치는 최초 밸런스 가설이며 실측 결과가 아니다.

## 조작과 화면

- WASD/방향키 이동, 자동 조준·공격. 대각 이동 속도를 정규화한다.
- 마우스 클릭 및 Enter로 메뉴 결정, 1/2로 캐릭터 선택, 1/2/3으로 성장 선택, P로 일시정지, R로 재도전한다. Esc는 에디터 PIE 종료와 충돌하므로 게임 필수 입력으로 사용하지 않는다.
- 16:9 기준 1280×720 가상 화면, 다른 해상도에서는 비율을 유지한다. 바닥보다 캐릭터·적·공격·경고의 명암 대비를 높인다.
- 타이틀은 ImageGen 폐허 성당·붉은 달 배경, 실제 제목·버튼은 런타임 텍스트로 표시한다.
- 선택 화면은 두 영웅의 전신 도트 아트와 체력·사거리·특성을 비교한다.
- HUD: 남은 시간, 체력, 경험치/레벨, 처치 수, 다음 위협, 보스 체력. 결과: 생존 시간, 처치 수, 레벨, 보스 처치 여부와 재도전/타이틀.

## 적과 위협

| 적 | 역할 | 기본 체력/속도/접촉 피해 | 출현 |
| --- | --- | --- | --- |
| Grave Thrall | 느리고 읽기 쉬운 해골 보행자 | 20 / 62 / 8 | 시작부터 |
| Bloodwing | 빠르지만 약한 자주색 박쥐 | 14 / 112 / 6 | 30초부터 |
| Iron Revenant | 둔중한 장갑 망령 | 68 / 48 / 14 | 60초부터 |
| Crimson Stalker | 경고 후 돌진하는 붉은 사냥꾼 | 34 / 88 / 10 | 105초부터 |
| Bellkeeper | 대형 뿔과 종 지팡이의 보스 | 900 / 42 / 20 | 150초에 한 번 |

일반 적은 경기장 가장자리 밖에서 출현하며, 보스는 상단에서 등장한다. 보스는 원형 파동 경고를 먼저 보여준다. 일반 적 상한 89에 보스 1칸을 예약하여 총 90을 유지하고, 경험치 상한 140으로 개체 증가를 제한하며 초과 경험치는 합친다. 보석은 이동 가능한 경기장 안으로 위치를 보정한다. 화살은 상한 60과 1.6초 수명, 시각 효과는 상한 100과 짧은 수명을 둔다.

## 180초 페이싱

| 전투 시간 | 전개 | 목적 |
| --- | --- | --- |
| 0–30초 | Thrall, 낮은 밀도, 첫 성장까지 약 15초 | 이동·자동 공격·경험치 습득 이해 |
| 30–60초 | Bloodwing 유입, 두 번째 성장 | 이동 경로 결정 |
| 60–105초 | Revenant와 일반 적 혼합, 치유 드롭 | 무기 성장 효과 확인 |
| 105–150초 | Stalker, 짧은 경고, 밀도 증가 | 회피와 위치 선정 |
| 150–180초 | Bellkeeper 등장, 잡몹 발생량 감소 | 마지막 압박과 선택 |

180초에 살아 있으면 기본 승리, 보스까지 처치하면 특별 승리다. 보스를 처치하지 못해도 정상 엔딩을 제공하여 3분 요구를 보장한다. 체력 0이면 즉시 패배. 결과 상태로 전환한 이후 전투 판정은 정지한다.

## 성장과 전투 피드백

적 처치 시 경험치 보석을 떨어뜨리고 가까워지면 흡수한다. 경험치 요구량은 낮게 시작해 증가하며 3분 동안 6–10회 선택을 목표로 한다. 레벨업 때 전투를 정지하고 중복되지 않는 성장 3개를 제시한다. 최대 단계에 도달한 항목은 제외하고 남은 항목이 부족하면 치유를 제공한다.

초기 경험치 요구량은 4이며 이후 `4 + Level × 7`로 증가한다. 성장 후보: 피해 +20%, 공격 간격 -12%(하한 0.18초), 이동 +10%(상한 340), 검사 범위 +18% 또는 궁수 화살 명중 반경 +2, 획득 반경 +30%, 최대 체력 +25 및 같은 양 회복, 궁수 추가 화살 또는 검사 베기 범위·피해·밀어내기. 일반 성장은 5단계, 고유 무기 성장은 3단계가 상한이며 상한 항목은 회복 카드로 표시·적용한다. 세 후보의 항목 번호는 서로 다르다. 최종 입력 테스트에서 궁수 레벨 8, 검사 레벨 10에 도달했다.

접촉 피해는 0.65초의 공통 무적 시간을 적용한다. 피격 깜빡임, 짧은 적 피격 색상, 공격 잔상과 방향, 처치 입자, 획득 반짝임으로 상태를 설명한다. 이미지가 모든 피드백을 담당하지 않도록 표준 엔진 도형과 색상 효과를 함께 사용한다.

## ImageGen 제작 명세

팔레트: 자정 남색, 바랜 청록, 뼈색, 피빛 적색, 작은 금색 포인트. 큰 색면·선명한 윤곽·제한된 색상·최근접 필터링으로 도트 느낌을 유지한다.

1. 타이틀 배경: 가로 화면, 붉은 달과 성당 폐허, UI를 위한 어두운 여백, 글자 없음.
2. 전장 배경: 위에서 내려다본 묘지 바닥, 명암을 낮춘 작은 묘비/돌길, 플레이 영역 명확, 글자·캐릭터 없음.
3. 영웅 아틀라스: 2열×2행, 위 Lyra/아래 Kael, 왼쪽 대기/오른쪽 걷기, 일정한 셀, 투명 배경.
4. 적 아틀라스: 3열×2행, Thrall/Bloodwing/Revenant/Stalker/Bellkeeper/경험치 보석 순서, 투명 배경, 각 셀 안에 완전히 들어가는 실루엣.

원본은 프로젝트 `Content/VampireSurvival/SourceArt`에 보존하고 게임용 텍스처는 `Art`로 임포트했다. 영웅 2×2, 적 3×2의 셀별 UV와 투명도를 실제 화면에서 확인했다. 그림 속 글자는 메뉴 정보로 사용하지 않는다. 기본 공격·피격·성장·선택·시작 효과음과 32초 칩튠 배경음은 독자적으로 합성하여 `SourceAudio`와 `Audio`에 보존했다.

## 구현과 검증 기준

게임 플레이 C++은 만들지 않는다. 기존 MCP/Unreal Python/Blueprint 편집 API를 우선 사용하고 구체적 부족 기능만 에디터 전용 Tivret MCP에서 보완한다. 다른 작업의 dirty Blueprint는 저장하거나 변경하지 않는다. 프로젝트 기본 맵과 기존 게임 설정은 유지하며 전용 맵으로 실행한다.

완료 증거: 생성 에셋 목록, Blueprint 컴파일/저장, 타이틀·선택·두 클래스 전투·성장·일시정지·사망·180초 결과·재시작 관찰, 이미지 화면 확인, 런타임 의존성 검사. 게임 시간이 짧아지는 가속 검사는 정상 180초 실행과 구분한다. 패키징/독립 실행 미수행 시 명시한다.
