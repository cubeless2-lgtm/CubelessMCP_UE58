# V5 전투 피드백·성장·드롭 및 버튼 수정

2026-10-27. `/Game/VampireSurvival/Maps/L_CrimsonDawn`. 샤미 마법사 / 미니에 검사. 이번 변경은 자체 검수이며 독립 QA는 수행하지 않았다. 최종 실행 결과는 `cubeless/records/verification/vampire-survival-v5/delivery_report.json`을 기준으로 한다.

## 입력과 일시정지

- 시작·강화·일시정지·재개·재도전 등의 일반 버튼은 **마우스를 누르는 순간 한 번 실행**한다. 누름 유지와 뗌은 추가 실행을 만들지 않는다.
- 영웅 카드는 한 번 클릭하면 선택 색을 표시한다. 같은 카드에서 0.5초 이내, 24px 이내로 두 번째 클릭하면 해당 영웅으로 즉시 시작한다. 다른 카드·느린 클릭은 선택만 한다.
- 기본·청록 오버·붉은 주황 누름·금색 영웅 선택 상태를 유지한다. 선택 화면은 기존 영웅별 16프레임 대기 모션을 사용한다. UI는 타이틀 로고를 제외하고 한글이다.
- 강화 선택은 표준 `SetGamePaused(true)`로 실제 월드를 멈춘다. 소유 HUD와 PlayerController만 정지 중에도 UI 입력을 처리한다. 게임 시계·적·투사체·출혈 등의 상태는 정지하고, 선택하면 즉시 재개한다. 키보드 1/2/3도 지원한다. P 메뉴의 기존 전투 정지도 유지한다.

## 타격과 적

ImageGen으로 적 5종의 피격 4프레임씩 총 20포즈, 마법 명중·검 명중·영웅 피격·출혈의 효과 4프레임씩, 녹색·빨간 구슬의 맥동 4프레임씩을 만들었다. PNG 원본은 `Content/VampireSurvival/SourceArt`에 그대로 보존했다. 최근접 필터, mip 없음, UI 텍스처를 사용한다. 비균일한 적 아틀라스는 원본을 편집하지 않고 셀별 UV/발 기준점으로 맞췄다.

- 직접 타격 시 적의 이동과 일반 공격 타이머를 0.1초 멈춘다. 피격 포즈는 0.18초 동안 4프레임을 재생한다. 출혈의 매 틱은 추가 경직을 만들지 않는다.
- 명중/피격 효과음, 짧은 전장 흔들림과 기존 영웅 피격 표시를 결합했다. HUD는 흔들리지 않는다.
- 점프 착지 넉백은 일반 적 110→220px, 보스 22→44px로 2배다. 기본 타격의 짧은 밀림은 별도로 적용한다. 기존 착지 공격 범위 표시, 점프 높이 225px, 급강하 375px, 쿨다운 10초를 유지한다.
- 각 적의 생성 당시 최대 체력을 저장한다. 현재 체력이 **50% 미만**이면 이동 속도는 기본의 70%다. 정확히 50%에서는 감속하지 않는다. 낮은 체력의 일반 적에는 작은 체력 막대를 표시한다.
- V3의 적 피해 30% 감소와 물량 설정을 유지한다. 이전 버전보다 피해를 다시 30% 줄이지는 않았다.

## 성장과 특수 스킬

레벨업 보상 100% 상향은 일반 강화의 효과량을 2배로 적용했다. 처치 경험치 10% 상향은 별도로 적용한다.

| 일반 강화 | 변경 후 | 최대 단계 |
| --- | --- | --- |
| 공격력 | 회당 +40% | 5 |
| 공격 속도 | 공격 간격 회당 -24%, 최소 0.12초 | 5 |
| 이동 속도 | 회당 +20%, 최대 550px/s | 5 |
| 범위 | 검사 베기 +36%, 샤미 명중 반경 단계당 +4px | 5 |
| 획득 범위 | 회당 +60% | 5 |
| 최대 체력 | +50 및 체력 50 회복 | 5 |
| 최대 단계 대체 회복 | 체력 60 회복 | 해당 없음 |

강화 메뉴마다 20% 확률로 세 슬롯 중 하나를 해당 영웅의 특수 스킬로 바꾼다. 슬롯별 20% 판정을 세 번 하지 않는다. 특수 스킬 3단계 이후에는 출현하지 않는다. 일반 후보는 서로 다른 종류다.

| 특수 스킬 단계 | 샤미: 마력 폭발 | 미니에: 감속과 출혈 |
| --- | --- | --- |
| 1 | 명중 중심 3m, 주변 피해 공격력의 60% | 일반 적 40% 감속 2.5초, 출혈 3초·초당 공격력의 20% |
| 2 | 같은 반경, 주변 피해 75% | 일반 적 50% 감속 3초, 출혈 4초·초당 30% |
| 3 | 같은 반경, 주변 피해 90% | 일반 적 60% 감속 3.5초, 출혈 5초·초당 40% |

1m=75px 기준이므로 샤미의 반경은 225px다. 직접 맞은 대상은 기본 피해를 한 번 받고 주변 대상만 비율 피해를 받는다. 폭발이 다시 폭발을 만들지 않는다. 기존 작은 기본 명중 폭발은 반경 65px다. 미니에의 출혈은 0.5초마다 피해를 주며 재타격은 지속시간을 갱신하고 피해량을 중첩하지 않는다. 보스 감속은 20/25/30%로 완화한다. 낮은 체력 감속과 스킬 감속은 곱해서 적용한다.

## 드롭

| 항목 | 확률 / 보상 |
| --- | --- |
| 기본 처치 경험치 | 일반 1.1, 강화 적 3.3, 보스 27.5로 이전보다 10% 증가 |
| 녹색 회복 구슬 | 처치마다 2%, 습득 시 최대 체력의 10% 회복, 최대 체력에서 제한 |
| 빨간 경험치 구슬 | 처치마다 5%, 해당 적의 기본 경험치만큼 추가 지급 |

회복과 경험치 구슬은 독립 판정이므로 둘 다 나올 수 있다. 앞선 처치 경험치 증가를 유지하면서 빨간 구슬은 추가 보상으로 적용한다는 해석을 작업 중 사용자에게 알렸다. 이 해석 때문에 경험치를 구슬 5%에만 의존하지 않는다. 경험치 HUD 아이콘도 빨간 구슬로 맞췄다. 구슬은 총 140개 상한이며, 상한에서 빨간 구슬의 경험치는 바로 지급한다. 녹색 구슬은 추가 생성하지 않는다.

## 자체 리뷰와 수정

1. 새 구슬을 텍스처 임포트 전에 그래프에서 참조해 기본값이 비어 있었다. 실제 전투 화면에서 보이지 않는 것을 찾아 저장된 텍스처로 다시 연결하고 화면을 재확인했다. 세 신규 효과 함수의 텍스처 연결도 검사했다.
2. 기존 HUD의 녹색 경험치 아이콘을 새 빨간 구슬로 교체해 드롭과 일치시켰다.
3. 0.4초 더블클릭 제한은 도구 입력 재검사에서 경계 타이밍으로 선택만 되는 사례가 있었다. 0.5초로 조정하고 새 PIE에서 실제 컨트롤러 입력을 다시 통과했다. 실패 접두 기록은 `doubleclick_400ms_failure.json`에 보존했다.
4. 출혈 사망이 적 배열을 제거하므로 전투 갱신을 역순으로 바꿨다. 여러 적의 동시 출혈 사망과 광역 동시 처치를 검사했다.
5. 기존 성장의 이동/공격 간격 제한에 일찍 막혀 강화가 무효가 되지 않도록 새 효과에 맞게 상한/하한을 조정했다. 특수 스킬의 추가 투사체·범위 중복 보상은 제거하고 새 효과로 통일했다.
6. 강화 메뉴를 단순 상태 번호 정지에서 실제 Engine pause로 바꾸고, 정지 중 UI 입력과 선택 즉시 재개를 확인했다.

## 검증과 재현

- 실제 Blueprint 함수에 대한 통제 검사 14묶음: 즉시 클릭·더블클릭·확률 경계·보상·드롭/회복·처치 XP·감속·경직·출혈·폭발 범위·넉백·동시 사망·Engine pause/재개. `combat_checks.json`.
- 실제 PIE 컨트롤러 마우스 위치 및 pressed/released 입력 10개 관측: 일반 버튼 누름 즉시 이동, 홀드 중 중복 없음, 영웅 선택/더블클릭 시작, 정지 중 오버와 강화 선택. 1.2초 관측 구간에서 월드/전투 시간·적·투사체·상태 배열이 동일했다. `input_pause.json`.
- `hero-selected.png`, `upgrade-paused-hover.png`, `combat-art-fixture.png`로 한글 배치·선택·효과·적 피격·두 구슬을 확인했다. 통제 화면은 자연 플레이 결과와 구분한다.
- 38개 에셋·90개 그래프의 저장/컴파일과 MCP 참조 검사를 수행했다. 상세 결과는 최종 보고서에 있다.
- 일반 속도 입력 플레이는 HP·시간·피해·경험치 변경 없이 외부 키 입력만 사용한다. `TestBot=false`. 영웅별 플레이 기록과 결과는 같은 증거 폴더의 `*_play.jsonl`, `*_result.json`이다.
- MCP/Toolset/Python 플러그인을 끈 별도 콘텐츠 전용 프로젝트에서 최종 Win64 Cook/Stage/Package를 수행했다. 실행 파일은 `Packaged/Windows/CrimsonVerify58.exe`. V5 패키지의 네이티브 Windows 클릭은 이번 검증 범위에 포함하지 않는다.

프로젝트·MCP·엔진 C++ 변경이나 새 런타임 의존성은 없다. 기존 V1~V4 자료는 보존했다. Git stage/commit/push는 수행하지 않았다. 생성 프롬프트는 `imagegen_prompts.json`, `orb_prompt.json`, 원본 셀 측정은 `hurt_uv.json`, 제작 스냅샷은 `authored_source.py`에 있다. 재제작 시에는 텍스처를 먼저 임포트하고 스키마 → 그래프 작성 → 활성 연결 → 검수 순서를 따른다. 단계 함수 전체를 이미 작성된 그래프에 재실행하지 않는다.
