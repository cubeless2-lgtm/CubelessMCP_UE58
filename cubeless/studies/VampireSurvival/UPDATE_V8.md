# V8 모바일 세로 화면

2026-10-27. `/Game/VampireSurvival/Maps/L_CrimsonDawn`을 **720×1280, 9:16 세로 화면** 기준으로 다시 구성했다. 키보드를 유지하면서 터치 조작을 추가했다. [V7 회복 조정](UPDATE_V7.md)과 [V6의10분 규칙](UPDATE_V6.md)은 유지한다. 최종 증거는 `cubeless/records/verification/vampire-survival-v8/delivery_report.json`이다.

## 화면 구성

- 타이틀과 전투 배경은 ImageGen으로 세로 구도로 새로 제작했다. 원본 PNG는 `Content/VampireSurvival/SourceArt/TitlePortraitV8.png`, `ArenaPortraitV8.png`다. 기존 영문 로고 `CRIMSON DAWN / TEN MINUTES`는 유지했다.
- 영웅 카드는 위아래로 배치하고, 각 카드의 왼쪽에는 기존16프레임 대기 모션, 오른쪽에는 이름·직업·체력을 표시한다. 한 번 선택하고, 같은 카드를 빠르게 두 번 누르면 즉시 시작한다. 별도 생존 시작 버튼도 유지했다.
- 강화 선택은 세로 카드3개다. 일시정지·승리·사망 결과와 버튼도 세로 배치로 바꿨다. 버튼은 누르는 순간1회 실행한다.
- HUD는 상단 체력·짧은 스태미너·시간·레벨·일시정지, 그 아래 경험치·처치·특수 스킬 단계다. 하단에는 왼쪽 이동 패드, 오른쪽 달리기·점프를 배치했다. 화면 밖으로 글자를 밀어내는 설명은 추가하지 않았다.
- 새 `PanelNineV8`는 모서리·가장자리·중앙을9개 영역으로 나눠 그려 크기를 바꿔도 모서리 장식을 보존한다. 새 `TouchControlsV8`에는 이동 패드와 손잡이·점프·달리기 아이콘이 있다. 원본을 편집하지 않고 최근접 필터로 사용한다.
- 긴9:20 화면은 중앙9:16 영역에 UI를 유지하고 배경을 비율에 맞게 잘라 전체 화면을 채운다. 검은 여백이나 배경의 가로 늘어짐을 피했다. UI 외곽 여백과 하단 버튼 공간을 확보했다.

## 조작과 스태미너

| 기능 | 기존 키보드 유지 | 화면 조작 |
| --- | --- | --- |
| 이동 | WASD / 방향키 | 왼쪽 패드 드래그 |
| 달리기 | Shift 누름 유지 | 달리기 버튼 누름 유지 |
| 점프 / 공중 착지 공격 | Space를 각각 한 번 | 점프 버튼을 각각 한 번 |
| 일시정지 / 재개 | P / Enter | 상단 일시정지 / 계속하기 |
| 영웅 선택 | 1 / 2, 좌우 방향키 | 카드 선택 / 더블 탭 시작 |
| 강화 선택 | 1 / 2 / 3 | 세로 카드 선택 |
| 시작 / 재도전 / 타이틀 | Enter / R / Backspace | 해당 버튼 |

스태미너 최대100에서 초당40을 소비하므로 연속 달리기는 약 **2.5초**다. 기존 회복 지연0.65초, 초당24 회복, 지침 해제25 기준은 유지한다. 스태미너 바는150가상 픽셀로 체력바270보다 짧다. 달리기 버튼은 지침 상태를 표시하고, 점프 버튼은 준비·공중 착지·남은 쿨다운을 한글로 표시한다. 실제 손가락/마우스 누름 때 강조 원을 표시한다.

런타임은 표준 `PlayerController.GetInputTouchState`로 최대5개 접점을 읽는다. 이동·달리기·점프·메뉴의 접점 소유권을 따로 관리해 이동하면서 다른 손가락으로 행동할 수 있게 했다. 터치가 있을 때는 마우스 중복 실행을 막고, PC에서는 마우스로도 패드와 화면 버튼을 시험할 수 있다. 기본 엔진 가상 조이스틱은 이 게임의 HUD 초기화에서 비활성화한다. 강화와 일시정지 중에는 Engine pause를 사용하고 UI 입력만 처리한다.

## 전장과 기존 규칙

가로 화면을 단순 축소한 것이 아니라 이동 경계를 `x40..680, y300..1050`으로 바꿨다. 시작 위치는360/650, 적은 세로 전장 가장자리에서 들어온다. 보스는360/290에서 출현한다. 구슬은45..675/310..1040 안으로 보정하고 투사체 제거 경계도720/1100에 맞췄다. 화면 위쪽 점프는 카메라가 여백을 확보하며, 흔들림과 카메라 복원에 화면 배율을 적용해 HUD가 따라 움직이지 않게 했다.

10분 종료,9분 보스,출현 단계50/133.33/200/250/300초,공격력 강화x1.2,샤미 특수 반경0.9m,특수 확률20%·최대3단계,대체 회복20·녹색 구슬 최대 체력5% 및 드롭2%는 유지한다. 점프 최고점225px,급강하375px,착지 반경95px,쿨다운10초도 유지한다. 전장 가장자리에서는 급강하 도착 위치를 경계 안으로 제한한다.

전용 콘텐츠 게임 프로젝트 `cubeless/workspaces/CrimsonVerify58`에는 Windows 세로 창 기본값540×960과 Android/iOS 세로 방향 설정을 넣었다. 가로로 열린 데스크톱에서는 시작1초 후 게임 갱신 루틴에서 표준 GameUserSettings를 통해 세로 창으로 맞춘다. Canvas를 그리는 중에는 창 크기를 변경하지 않는다. 모바일에서는 이 데스크톱 전용 처리를 실행하지 않는다. 기본 Unreal 프로젝트의 다른 맵·렌더러·플랫폼 설정은 바꾸지 않았다. 에디터의 새 PIE 창은432×768로 맞춘다.

## 자체 검수와 증거

- 실제 Blueprint 통제 검사8묶음에서 다중 접점 소유권,아날로그 이동,2.5초 스태미너,세로 경계,점프 높이·급강하·쿨다운,보스·구슬 위치,회복 보상,Engine pause·600초 종료·영웅 더블 탭 신호를 확인했다. `mechanics_checks.json`.
- 실제 PIE 키보드/마우스 입력17관측과8개 화면의 실제 DrawHUD 글자 치수를 확인했다. 360×800의 긴 세로 화면에서도8개 화면을 확인했다. `ui_checks.json`, `aspect360x800/checks.json`. 손가락 소유권 검사는 실제 Blueprint 함수에 좌표를 주는 통제 검사이며 실기기 터치 시험과 구분한다.
- 샤미 투사체가 기존720px 아래의 적을 타격하는 것,미니에 근접 공격과 출혈,상단 점프가 HUD/보스바를 가리지 않는 것을 추가 확인했다. `combat_camera_checks.json`.
- 시간·체력·경험치·피해를 바꾸지 않는 외부 키 입력으로 샤미 약93초,미니에 약69초의 일반 속도 플레이를 확인했다. 둘 다 진행 중에 검수 시간 제한으로 끝냈다. 원 드라이버의 `pass:false`는600초 승리 미달이며 패배가 아니다. V8의 전체600초 완주 증거로 세지 않는다.
- 신규4텍스처와 소유 HUD/컨트롤러 변경만 저장했다. 최종 컴파일·의존성·입력 해시·Windows 패키징·실행 해상도는 최종 보고서에 기록한다. 프로젝트·MCP·엔진 C++은 추가하거나 수정하지 않았다.

검수 중 점프 버튼 문구의 중첩 문자열 선택이 숫자로 변환되는 것을 찾아 명시적인 상태 문자열로 고쳤다. 선택 카드의 과한 색 덮개를 줄이고 터치 누름 강조,일시정지 터치 범위,상단 점프 여백을 보강했다. 처음 기본 설정만 쓴 패키지는 실제로1066×600으로 열려 데스크톱 최초 세로 전환을 추가했다. 초기 DrawHUD에서 즉시 창 크기를 바꾸는 구현은 독립 실행 시 Canvas 수명 충돌을 일으켰으므로 게임 갱신 루틴의 시작1초 이후로 옮겼다. 원 실패 화면과 충돌 로그를 보존했다. 핀 수정의 값 충돌·리플렉션 속성 이름·문자열 함수 소속을 잘못 가정한 작성 실패는 현재 노드와 적용 접두를 읽어 남은 부분만 이어서 처리했다. 불확실한 수정 전체를 재실행하거나 기존 사용자 작업을 일괄 저장하지 않았다.

최종113그래프는 컴파일 오류0,43개 에셋의 금지 런타임 참조0이며 패키징 입력 해시가 원본과 일치한다. Win64 Cook/Stage/Package는 ExitCode0으로 끝났다. 창 크기 인수 없이 실행한 독립 프로세스의 로그에서 시작 후540×960 전환과 충돌·Canvas 수명 경고가 없음을 확인했다. 초기 스크린샷은 전환 이전에 촬영되므로 최종 타이틀 이미지는 별도 실행에서 `-ResX=540 -ResY=960 -ForceRes`로 캡처했다. `ForceRes`는 오프스크린 데스크톱 크기 제한을 우회하기 위한 검증 인수이며 자동 전환 증거와 구분한다. PIE 키보드·마우스17관측과16화면의2100개 글자 치수를 통과했다. 종료 시 PIE=false,dirty=[],TestBot=false,RecordUILayout=false,PortraitInitialized=false를 확인하고 검증 소유 패키지 프로세스를 정리했다.

실제 Android/iOS 패키지,휴대폰 터치·노치·성능·메모리,네이티브 Windows 클릭과 독립 QA는 미검증이다. 이번 산출물은 세로 화면 게임 에셋과 Windows 미리보기이며 APK/IPA를 제공한 것으로 주장하지 않는다. 새 이미지 프롬프트는 `imagegen_prompts.json`,원본·설정은 `art_manifest.json`과 `platform_config.json`,제작 소스는 `authored_source.py` 및 `create_v8.py`다.
